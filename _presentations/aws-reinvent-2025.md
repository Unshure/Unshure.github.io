A presentation I shared with [Ryan Coleman](https://www.linkedin.com/in/ryanycoleman/) about the newly released Strands TypeScript SDK. My portion covered how I created agentic GitHub workflows to write the TypeScript SDK. The agents used [Agent SOPs](https://github.com/strands-agents/agent-sop) to guide them through interacting in GitHub, prompted through issues and pull requests.
